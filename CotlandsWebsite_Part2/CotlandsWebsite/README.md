# Cotlands Website - Part 2

## Part 2: CSS Styling and Responsive Design

This project builds on the Part 1 Cotlands website.

### Changes implemented

- Created and populated an external stylesheet: `css/style.css`.
- Applied a CSS reset and consistent base typography.
- Added desktop layout styling using Flexbox and CSS Grid.
- Added visual styling including colours, borders, shadows and hover/focus states.
- Added responsive breakpoints for tablet and mobile screen sizes.
- Changed multi-column sections to single-column layouts on smaller screens.
- Added responsive image handling with `max-width: 100%` and `height: auto`.
- Added a responsive hero/banner using the supplied `banner.jpg`.
- Improved form styling and keyboard focus states.
- Normalised HTML filenames to lowercase so navigation links work consistently.
- Corrected the stylesheet and JavaScript paths.
- Added basic client-side form feedback.
