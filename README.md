## Responsive Design

The website has been designed to adapt to different screen sizes.

### Desktop
The website uses multi-column layouts where appropriate.

### Tablet
Content sections adjust to fewer columns and the navigation adapts to the available space.

### Mobile
Content changes to a single-column layout, navigation becomes vertically arranged, and buttons and forms expand to fit the screen.
